# P07 explicit-core evidence adapter, V2 study draft

The module is an additive, pure validator. Construct `TrustedPins` only from an independently reviewed record, including whole archive bytes hash, exact checkpoint member and hash, native raw and canonical V1 trace hashes, model/core, selected named core, source closure, and this adapter's file hash. Never generate these expected values from the same untrusted submission. Supply the exact ZIP bytes and tagged A/B JSON, with the explicit core choice. Before any external execution, `prepare` checks the ingress and returns detached data in original source object-key order; tag pairs are positional and identity-sensitive. If A and B payloads are identical, tags detect reordered rows, not indistinguishable bare-value swaps.

An external, reviewed runner (not supplied here) must bind actual callable paths and startup/ending source closure, require stock `selected_core` and `assemble` with the prepared values, check its no-solver rule and bounded lifetime, read back output with stock tuple/JSON transport, and leave originals unchanged. Source roles here are caller labels for bytes, not checks on imported modules. This module has no process, imports no stock code, and cannot prove the caller ran anything. `seal` rechecks the input and both supplied source snapshots and compares the supplied model/core canonical digests with the independent archive pins. Passing only means the supplied objects match, even if they were copied directly from the archive. The exact wire target is the V1 member substring; V1 canonical hash and result model/core identities follow native sorted JSON hashing, not byte-for-byte egress.

Adaptive replay is distinct from the original V1 construction verdict or historical physical report. This code neither consumes their conclusions as authority nor changes/recomputes them. It has no link to product UI/routes, acceptance, release, or evidence durability. A future branch can coexist only as isolated study code with the original frozen source guard unchanged; any supported runner must be reviewed separately for source closure, authenticated anchor acquisition, resource limits, private data handling, and normal CI. No production wiring implied.

Synthetic stdlib tests: `PYTHONDONTWRITEBYTECODE=1 python -m unittest -v`.

# Planha Architecture

این مخزن خصوصی، مرجع توسعه از این پس است. تغییر کد فقط در GitHub انجام می‌شود؛ نسخه مک و محیط ابری نباید برای توسعه ویرایش شوند.

## وضعیت انتقال: در حال تکمیل
این commit کد adapter و آزمون‌های محلی را منتقل می‌کند، نه کل بسته اجرایی. وابستگی موتور و closure تاریخی هنوز کامل منتقل نشده‌اند؛ اجرای کامل از این commit ادعا نمی‌شود.

- دامنه جاری هر محور: ۵ تا ۲۵ متر، شامل دو سر؛ خارج دامنه خطا و بدون clamp.
- بررسی/اصلاح، تاریخچه، لغو، گیت عملکرد و بررسی تنوع به adapter متصل‌اند؛ پذیرش معماری و تحویل همچنان false است.
- `kitchen_guest_review.py` و `candidate/bundle25` آزمایشی و ادغام‌نشده‌اند.
- `service_gate` فقط wrapper مرحله‌ای آزموده‌شده است؛ rollout سرویس‌های قدیمی انجام نشده و نسخه اصلی۱۵۰ پس از rollback سالم بود.
- اصل معتبر۵۸۸ بازیابی نشده؛ این پروژه بازسازی۵۸۸ نامیده نمی‌شود.
- آزمون‌های تاریخی۱۱۲Python و۲۷سناریویJS روی مک اجرا شده‌اند، نه CI این مخزن. بعضی تست‌ها به داده‌های هنوز منتقل‌نشده وابسته‌اند.
- تولید تازه۲۵×۲۵ در adapter صفر مدل داد؛ محدودیت دو خانواده موجود است، نه اثبات ناممکنی زمین.

هیچ دیتابیس، credential، محیط مجازی یا داده شخصی نباید commit شود. پین‌های تاریخی برای نمایش موفقیت دستکاری نمی‌شوند. تکمیل انتقال وابستگی‌ها و راستی‌آزمایی روی GitHub هنوز باز است.

## انتقال مرحله دوم و سوم
۴۷۹ فایل منتخب موتور و منابع مرجع منتقل شده‌اند. متن قرارداد و schema تنها به علت مصرف مستقیم در evaluator، inventory، بازپخش و ممیزی source-pin یا ضرورت توسعه و آزمون همراه منتقل شده است؛ سند کامل Blueprint/PRD بارگذاری نشده است. نتیجه تاریخی بدون مصرف شناسایی‌شده کنار گذاشته شد. شرح ضرورت و موارد باز در [MIGRATION_STATUS.md](MIGRATION_STATUS.md) آمده است.

closure تاریخی بزرگ‌تر، frontend و داده‌های تست هنوز کامل وارد نشده‌اند. این مخزن هنوز بسته مستقل قابل اجرا نیست و هیچ قبولی CI ادعا نمی‌شود.

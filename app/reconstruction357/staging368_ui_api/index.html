اجرای قابل‌ردیابیِ ورودی، تولید و بررسی

این نسخه فقط درخواست ۲۶ × ۲۸ متر، دو واحد و دو پلان را پشتیبانی می‌کند. برنامهٔ منبع سه‌خواب است. پشتیبانی از تمام بازهٔ ۵ تا ۴۵ متر هنوز اثبات نشده است. قبولی مفهومی به معنی تأیید فنی یا آماده‌بودن برای ساخت نیست.
تغییر ورودی نتیجهٔ قبلی را از نمایش خارج می‌کند؛ اجرای شروع‌شده با بستن صفحه لغو نمی‌شود. هم‌زمان فقط یک اجرا مجاز است.
هنوز اجرایی آغاز نشده است.
